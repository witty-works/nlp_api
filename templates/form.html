How to use this form?

If Witty doesn't work yet on the website you need, you can always copy&paste your text into this text field to use Witty.

Note you will still need to have Witty installed.

  1. Register to get the installation link.
  2. Install Witty in Chrome, Microsoft Edge and Firefox. For now, it only works in these browsers.
  3. Copy&paste your text into the above form. Inclusive and non-inclusive terms will be highlighted in real-time.
  4. If you encounter any issues please report a bug.
